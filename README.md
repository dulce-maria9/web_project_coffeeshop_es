# Triple Espresso

Este proyecto consiste en una página web cuyo objetivo principal es presentar el café de especialidad en Triple Peak.
La página permite:

- revisar los horarios de servicio
- Hacer reservas en el café para hasta 8 comensales

El proyecto fué realizado con las siguientes tecnologías:

- HTML para la estructura del sitio
- CSS para el diseño y estilos visuales.

Planes de mejora:

- Mejorar el diseño visual, aplicando animaciones que hagan más llamativo el sitio.
- Hacer el sitio responsivo, de modo que se adapte según el dispositivo desde el que se acede para su mejor visualización.
- Agregar nuevas funcionalidades, como validación del formulario y confirmación de la reserva.
